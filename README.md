# Eurekup

Genera una web app que combina lo mejor de Telegram y Google Drive



Actúa como un Senior Product Designer + Senior Full-Stack Developer.

Tu objetivo es rediseñar y construir una web app de mensajería y gestión de archivos completamente funcional, solucionando errores críticos y aplicando un diseño moderno, minimalista y altamente usable.

---

# 🎯 OBJETIVO PRINCIPAL

Crear una app:

- Intuitiva

- Rápida

- Sin errores

- Visualmente moderna (estilo premium)

- Funcional en móvil, tablet y escritorio

---

# 🧨 1. CORRECCIÓN DE ERRORES CRÍTICOS (PRIORIDAD ALTA)

Implementa soluciones reales para:

- Evitar duplicidad de contactos (validación única por usuario/email)

- Arreglar envío de archivos (upload estable + feedback)

- Activar envío real de emails en referidos

- Sincronizar almacenamiento con datos reales

- Permitir creación de canales privados/cerrados

- Sistema de referidos:

  → +1GB por usuario verificado

---

# ⚠️ SEGURIDAD UX

Implementar confirmación obligatoria (modal/banner) antes de eliminar:

- Canales

- Usuarios

- Archivos

- Carpetas
